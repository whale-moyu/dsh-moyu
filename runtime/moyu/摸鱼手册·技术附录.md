## 附 A 默认值总表

**这是出厂设置，不是建议值。** 你改过的以 `config.json` 为准。

### 时间与钱

| 项 | 默认值 | 在哪改 |
|---|---|---|
| 计时方式 | 按固定时长 | `window.mode` |
| 时长 | 120 分钟（最长 70 小时 59 分） | `window.durationMinutes` / `-Minutes` |
| 时间段 | 21:00–23:30 | `window.timeRange` / `-TimeRange` |
| 时间段跨天 | 0–2 天 | 同上（格式 `D:HH:MM-D:HH:MM`） |
| 绝对阈值（立刻停） | 5 元 | `budget.absoluteYuan` / `-Budget` |
| 提醒阈值（安全退） | 60%（5 元时 = 3 元） | `budget.remindPercent` |

## 附 B 配置文件字段速查

`config.json` 全貌（出厂值，`config.default.json` 同）：

```json
{
  "version": 1,
  "budget": { "absoluteYuan": 5, "remindPercent": 60 },
  "wake": { "maxCount": 0, "intervalMinutes": 30 },
  "window": { "mode": "duration", "durationMinutes": 120, "timeRange": "21:00-23:30" },
  "paths": { "writable": ["freetime/"], "readonly": "all", "protected": [] },
  "permissions": { "runCommands": "playground", "networkReadonly": true },
  "rejection": { "mode": "off" },
  "watch": { "outer": true, "outerOnCrashOnly": false }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `window.mode` | `duration` / `timeRange` | 计时方式 |
| `window.durationMinutes` | 数字 | 固定时长，分钟 |
| `window.timeRange` | `D:HH:MM-D:HH:MM` | 时间段，`D` 是「第几天」，0–2 |
| `budget.absoluteYuan` | 数字 | 绝对阈值，元 |
| `budget.remindPercent` | 数字 | 提醒阈值，占绝对阈值的百分比 |
| `wake.maxCount` | 数字 | 内续次数上限，0 = 不限 |
| `wake.intervalMinutes` | 数字 | 内续间隔，分钟 |
| `watch.outer` | 布尔 | 外守开关 |
| `watch.outerOnCrashOnly` | 布尔 | 只在崩溃日志出现时才拉 |
| `rejection.mode` | `off` / `deny` / `judge` | 拒绝权三态 |
| `permissions.runCommands` | `false` 或地盘名 | 「跑」的默认值：关，或某块地盘（没有 full） |
| `permissions.networkReadonly` | 布尔 | 「联」的反向开关（true = 只读网络） |
| `paths.protected` | 数组 | 额外要加锁的路径（应包含 DSH 程序本体，因机器而异） |

## 附 D 几条行为说明（2026-11-01 起）

### 进入只认设置

`moyu.cmd enter` 后面跟的 `-Budget` / `-Minutes` 已经不起作用了——窗口时长和额度只认设置页（`config.json`）。带了参数不会报错，只会打一行 `note: ignored ...` 并记进 `boundary.log`。

摸鱼中想改额度：改不动。`config.json` 在安全锁里，直接写和走接口都会被拒（`EPERM`）；退出后恢复。

### 设置页会显示「实际窗口」

设置页最上面除了设置值，还会有一行 `实际窗口：N 分钟 · X 元`。它读的是 `state.json`，不是配置——所以如果实际窗口和设置对不上（比如有人动了 state），那里会多一行橙红色警告。

守夜人也会在后台比对：对不上就往 `logs/guard.log` 写 `drift: ...`。两边都能留痕。

### 截图认字的退出码

1 出错、3 动作配额、7 不在摸鱼窗口。

### 键鼠守卫的两处改法（2026-11-09）

1. **`move` / `wheel` 的判据：前台窗口 → 光标落点窗口。**
   先用 `[Desk]::WindowFromPoint()` 拿到落点下的 hwnd，再走 `Assert-Guard <hwnd> 'move:under' -ReadOnly`。日志里 `what=move:under` / `wheel:under`（旧版是 `move:foreground`）。
   起因：跑完 shell 命令后控制台抢了前台，导致所有 move 被拒 `forbidden-process:powershell`。

2. **新增 `reveal` 动作。**
   `SetWindowPos(hwnd, HWND_TOP, SWP_NOSIZE|SWP_NOMOVE|SWP_NOACTIVATE|SWP_SHOWWINDOW)` —— 提到最前但不激活。返回 `{Title, Revealed, IsForeground}`；与 `focus` 同受 `guard.json` 的 `allowApps` 约束，日志 `kind=reveal`。

备份：`desktop.ps1.bak-under-20261109`、`desktop.ps1.bak-reveal-20261109`。

## 地盘字段（2026-11-16 补 user）

| 字段 | 类型 | 说明 |
|---|---|---|
| `label` | string | 设置页显示的名字 |
| `write` | string[] | 能写的目录（`moyu_run` 的 cwd 必须落在其中一块） |
| `run` | string[] | 能起的程序名（裸名，不带 .exe） |
| `net` | bool | 这块地盘允不允许出网；false 时 `moyu_fetch` 也拒 |
| `timeoutMs` | number | 单次执行上限，最大 6 小时 |
| `user` | string | `"moyu"` = 以受限账号执行（L3）；空/缺省 = 不换身份 |
