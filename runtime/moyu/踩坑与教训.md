# 摸鱼模式 · 踩坑与教训（2026-11-17）

这份东西不是说明书，是**病历**。每一条都是真发过的病：症状 → 真因 → 修法 → 教训。
写给两种人：拿到这个插件想改的人，和正在被同一个坑咬住的人。

一句话总纲：**这台机器上大部分「玄学故障」都不是玄学，是编码、路径、权限、进程边界四件事里的某一件事。**

---

## 一、PowerShell 与编码（最容易咬人，占了一半的坑）

| 症状 | 真因 | 修法 |
|---|---|---|
| 改完 `.ps1` 突然报几十个语法错，标点全红 | 文件丢了 UTF-8 BOM，PS 5.1 按 ANSI 读中文 | 写回时 `'\uFEFF' + text`，行尾统一 CRLF，`UTF8Encoding($true)` |
| `The term '﻿#' is not recognized` | BOM 叠了两层（`EF BB BF EF BB BF`） | 先 `TrimStart([char]0xFEFF)` 再补一次 |
| `.cmd` 里的中文注释变成 `??`，甚至整个任务不执行 | `.cmd` 被写成 UTF-16/UTF-8 带 BOM | `.cmd` 一律纯 ASCII，中文只放 `.ps1` `.md` |
| 计划任务点了没反应 | `restart-once.cmd` 被 `UnicodeEncoding` 写过 | 同上，cmd 必须 ASCII |
| `"$userName:(OI)(CI)M"` 报 `Variable reference is not valid` | PowerShell 把 `$userName:` 当驱动作用域 | 写成 `"${userName}:(OI)(CI)M"` |
| `node -e "...')))..."` 报奇怪的语法错 | pwsh 先把引号吃掉了 | 复杂脚本一律写成 `.mjs` 再 `node 文件` |
| heredoc 里反斜杠、反引号被吃掉，路径写歪 | bash/heredoc 转义层数不对 | 同上：写文件，不写内联脚本 |

**教训**：这台机器上「改完就崩、而且崩得莫名其妙」的第一嫌疑永远是编码。改任何 `.ps1`/`.cmd` 之前先确认三件事：BOM、CRLF、ASCII 范围。

## 二、用脚本改脚本：JS 的替换串有坑

| 症状 | 真因 | 修法 |
|---|---|---|
| 补丁跑完，目标文件变成一坨、`Parser` 报「方法调用中缺少 )」 | `str.replace(anchor, block)` 里 block 含 `$'`，JS 把它当「匹配之后的剩余文本」 | **替换串里有 `$` 必须用函数形式**：`str.replace(anchor, () => block)` |
| 补丁脚本报 `anchor missing`，明明字在现场 | 文件是 CRLF，锚点写的是 `\n` | 先 `split('\r\n').join('\n')` 再匹配，写回时还原 |
| 补丁「成功」了但实际没改 | 锚点写错一处，脚本在写盘前 throw，看着像成功 | 每步 `node --check` / `Parser::ParseFile`，别信 exit 0 |

## 三、配置文件：坏一个字符，整块能力消失

| 症状 | 真因 | 修法 |
|---|---|---|
| 地盘全没了，只剩内置的「游乐场」 | `JSON.parse` 遇到 BOM 抛错，被 `catch` 吞掉，配置被当成不存在 | 读时 `.replace(/^\uFEFF/,'')`；写时保留 BOM（PowerShell 那边读中文才不会乱） |
| 手写坏配置后，进摸鱼直接不能用 | 同上，静默回落 | 现在有 `config.lastok.json` 快照 + `config-error.log`，坏的时候继续用上一份好的 |
| 状态读不出来，整个摸鱼状态空白 | `state.json` 同样的坑 | 同样加 `state.lastok.json` + `state-error.log` |

**教训**：任何「读配置」的地方，**失败必须留痕**，不能静默回落到默认值——默认值往往等于「什么都放开」。

## 四、拆代码：拆分本身最危险的不是逻辑，是 import

| 症状 | 真因 | 修法 |
|---|---|---|
| 重启后所有 `moyu_*` 工具报 `unknown tool` | 拆出去的模块忘了 `export`，主文件具名 import 拿到 `undefined`，模块加载失败 | 拆完必须 `node -e "import('./lib/policy.js')"` 列导出 |
| 同样症状 | 拆出去的模块引用了留在原文件的常量（`GATE_LAST` 等） | 常量跟着函数走，别留在原地 |
| `node --check` 通过但运行时 `ReferenceError: base is not defined` | 变量名在重构时改错，语法合法 | **`node --check` 查不出未定义变量**；必须有 smoke 冒烟 + 重启后真调一次 |

**教训**：`node --check` 只证明「能 parse」。真正的保险是「重启后真调一次工具」。

## 五、退出流程：两条路，漏一条就少一半收尾

| 症状 | 真因 | 修法 |
|---|---|---|
| 退出后日记没写、流水没记、报告没生成、浏览器没关 | 有两条退出路径：工具 `moyu_exit`（`doExitMoyu()`）和命令行/到点 `moyu.ps1 exit`。改造只挂了一条 | 凡是「退出时该发生的事」，两处都要挂；审查看 `sessions.log` / 日记 / 报告三份对不对得上 |
| 一进摸鱼就被判「边界被外面改过」，然后又退 | `tamperExit()` 清了 `boundaries` 却没清 `boundaryStamp`/`scopeStamp`，下次一进来就对不上 | 清状态要连带清指纹；两处退出都清 |
| 篡改退出后任务/代理/浏览器残留 | 篡改退出这条分支没走收尾 | 补 `schtasks /delete`、停代理、关浏览器、自动解锁 |

## 六、进程与作业对象（Job Object）——最反直觉的一类

| 症状 | 真因 | 修法 |
|---|---|---|
| 脚本跑完，它启动的 Edge/游戏立刻死 | DSH 每次工具调用外套一个作业对象，脚本一退出整个作业被关，子进程连坐 | 用 `CREATE_BREAKAWAY_FROM_JOB` 的启动器（`hidden-run.exe`）重生自己，再由它去起子进程 |
| 在工具调用里直接执行 `restart-once.cmd`，DSH 关了没起来 | 脚本杀 DSH 的同时自己也在同一作业里，被一起杀了 | 杀 DSH 的脚本**必须**用计划任务跑（`schtasks /run`） |
| 重启后连续崩两次，日志 `0xE0000008` | 旧实例没退干净就起了新实例，两个抢同一个单实例锁 | 杀完要**轮询等到一个不剩**（最多 30 秒），还有残留就放弃启动，别硬起 |
| 一个 `moyu_run` 60 秒才返回 | `spawnSync` 等到超时；PS 侧没及时退出 | `detached` 分支走「起完就返回」，不要等 |

**教训**：这台机器上「子进程无故消失」先怀疑作业对象，不要怀疑程序自己退出。

## 七、权限与 ACL

| 症状 | 真因 | 修法 |
|---|---|---|
| `icacls /deny "用户:(RX)"` 在 E 盘无效：列表读不了，单文件照读 | 某些盘的继承/显式权限叠加，`(RX)` 拒不到 | **一律用 `(F)` + `/T`**，别用 `(RX)` |
| 「封印」的日记打不开了，连自己都读不了 | `icacls` 的 `W` 包含 `SYNCHRONIZE`，一并把读也拒了 | 用具体权限 `(WD,AD,WEA,WA,DE)`，不含 `S` |
| `.dsh` 下的脚本以受限账号跑，报「拒绝访问」/`EPERM lstat` | 受限账号穿不过 `.dsh` 这一层 | 游乐场挪到 `C:\Users\<你>\AkPlay`；或者只给需要的那个子目录授 `(OI)(CI)RX` |
| `Start-Process -Credential` 起不来，报「目录名无效」 | 没给 `-WorkingDirectory`，或者工作目录/输出目录目标用户读不到 | 显式给 `-WorkingDirectory`，临时文件放到目标用户能读的地方（不要用 `%TEMP%`） |
| 新建的账号在登录界面看不见 | 账号没加进 `Users` 组，交互登录权限只认这个组 | `Add-LocalGroupMember -Group Users -Member <账号>` |
| 两个 profile 目录，改了 hive 不生效 | 注册表 `ProfileList` 指向的是 `C:\Users\akweb.MICROSO-FSK8SEO`，不是 `C:\Users\akweb` | 以 `ProfileList\ProfileImagePath` 为准 |

## 八、网络与防火墙

| 症状 | 真因 | 修法 |
|---|---|---|
| 按账号拦回环完全无效，浏览器照样连上 127.0.0.1 | Windows 防火墙**不过滤回环流量** | 回环要拦只能靠代理/应用层，不能靠防火墙 |
| 写好的防火墙规则像不存在 | 当前活动网络配置档（Public/Private）的防火墙是关的，规则不生效 | 先 `Set-NetFirewallProfile -Enabled True`，再谈规则 |
| 规则只对某档生效，换个网络就失效 | 规则 `Profile` 只列了 Domain/Private，实际在 Public | 内网服务统一 `Profile Any` + `RemoteAddress LocalSubnet` |
| Edge 策略 `FileUrlNavigationEnabled` 写了没用 | 这版 Edge 能读到策略，但状态标「错误」，不执行 | 别指望它；改走权限（让账号读不到）+ 应用层拒 |

## 九、浏览器自动化（CDP）

| 症状 | 真因 | 修法 |
|---|---|---|
| `c.on is not a function` / 事件全丢 | 极简 CDP 客户端只处理了 `id` 回包，`msg.method` 事件没分发 | 连接时加 `on(method, fn)`，先分发事件再走 id 回调 |
| 下载永远不落地，日志也没有 | `setDownloadBehavior` 指到的目录不存在，**静默失败** | 起浏览器前先建目录并授权 |
| 点了 `target=_blank` 的结果链接没反应 | JS 点击触发的弹窗被拦 | 点完检查 `location.href` 没变就 `Page.navigate` 兜底 |
| 正文只抓到「国内版 国际版」 | 取的是第一个命中容器 | 遍历候选取 `innerText` 最长的，短于 300 字退回 `body` |
| 合成鼠标点击（`mouse_event` / `PostMessage`）在 Electron 界面上完全无效 | Electron 不认合成输入 | 界面上要验的东西只能请人点，别浪费时间去模拟 |

## 十、计划任务

| 症状 | 真因 | 修法 |
|---|---|---|
| 计划任务「成功」但什么也没干 | `hidden-run.exe` 只吃**一个**引号包裹的整串命令行；传两段参数等于只执行第一段 | 参数整串包好，或者指向一个 `.cmd` |
| 同上，而且更狠：**一分钟起一个 node，攒了一千多个，吃掉 56GB 提交内存** | 就是上面那条：`hidden-run.exe <node> <gate.mjs>` 只跑了 `<node>`，没有脚本参数，进程挂着不退 | 现在 doctor 有「进程泄漏」和「任务参数」两项检查；到点任务必须实测一次 |
| `schtasks /change /tr` 之后任务会闪黑框 | 它把 execute 改成了 `cmd.exe` 本体 | 用 `New-ScheduledTaskAction -Execute ... -Argument ...` + `Set-ScheduledTask` |
| 用 `Register-ScheduledTask -Argument` 建出来参数是空的 | 本机行为，参数被吞 | 同上，改用 `schtasks /create /tr` 指向 `.cmd` |

## 改这个插件之前，先过这十条

1. 改 `.ps1`：BOM + CRLF + `Parser::ParseFile` 验证，三件缺一不可
2. 改 `.cmd`：纯 ASCII
3. 改 `.mjs`：`node --check` + `import()` 列导出
4. 改 `config.json`/`state.json`：读时去 BOM，写时留 BOM，坏数据要留痕
5. 用 JS 改文件：替换串里有 `$` 就用函数形式；文件是 CRLF 就先归一
6. 拆模块：常量跟着函数走，`export` 一个都别漏
7. 加「退出时要做的事」：两条退出路径都挂
8. 起子进程：想让它活得比脚本久，就得脱离作业对象
9. 碰 ACL：`(F)` + `/T`，别用 `(RX)`
10. 改完一定**重启后真调一次**：`node --check` 查不出未定义变量，也查不出 import 拿到 `undefined`

## 最后一件事：报告会说谎

这个插件里有三处「给人看的数字」：摸鱼报告、会话流水、退出审计。
它们曾经同时说谎——动作数恒为 0（读了一个从没生成过的日志）、退出方式显示英文、日记行数读错目录。
都是 `doctor` 报警才发现的。

现在的做法：`tools/report-selftest.mjs` 造一份已知内容的假账本，跑一遍报告，逐项核对正文里的数字，出现 `NaN`/`undefined`/`null` 也算失败。**给人看的东西必须能自证。**
