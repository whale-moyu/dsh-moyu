# 摸鱼模式 · 文档地图（2026-11-17）

同一件事以前在三四个文件里各说一遍，改一处忘一处，结果说法互相打架。这份表定「谁负责说什么」，以后只改负责的那份。

| 文件 | 谁看 | 只负责 | 不该写 |
|---|---|---|---|
| `摸鱼模式-人话版.md` | 用户、任何第一次接触的人 | 这是什么、怎么进出、四道闸、出事怎么办 | 命令、路径、字段名 |
| `摸鱼手册.md` | 我（进摸鱼前）/ 需要操作的人 | 怎么用：进去做什么、工具怎么调、退出流程 | 代码级的为什么（那是附录） |
| `摸鱼手册·技术附录.md` | 改代码的人（我） | 实现细节：文件在哪、函数叫什么、参数怎么算 | 使用说明 |
| `边界模板.md` | 想加地盘的人 | 一块地盘怎么填（填空式）、绝不能放什么 | 插件整体说明 |
| `预约启动.md` | 想让它到点自己开的人 | 排单怎么排、闸的判据、顺延、冷却 | 其它任何事 |
| `plugins/dsh-moyu-badge/README.md` | 拿到包的人 | 安装、7 个页签各是什么、安全默认、怎么回滚 | 摸鱼里的玩法 |
| `TASKS.md` | 我 | 欠什么、做完什么、什么时候改的主意 | 使用说明、实现细节 |
| `文档地图.md`（本文件） | 我 | 上面这张表 | 其它 |

## 一条规矩

**要写新东西之前，先看这张表，找负责的那份写。** 想在第二份里再写一遍，就先在那边留一句「见 X」。重复本身不是错，两处说法不一样才是。
