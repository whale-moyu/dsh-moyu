# 摸鱼：预约启动（2026-11-16）

三种启动方式共用一道闸，闸名 `Moyu-AutoEnter`（计划任务，每分钟跳一次）。

## 怎么用

```bat
:: 立刻（还是老样子）
moyu.cmd enter

:: 延时 30 分钟后可进（到点会先问你）
node "%USERPROFILE%\.dsh\moyu\grant.mjs" add +30

:: 今晚 22:30，免确认（你说了算）
node "%USERPROFILE%\.dsh\moyu\grant.mjs" add 22:30 --no-confirm 夜里自己玩会

:: 看还有什么挂着
node ...\grant.mjs list
:: 确认（默认版必须做这一步，十分钟内有效）
node ...\grant.mjs confirm <id>
:: 取消
node ...\grant.mjs cancel <id>
```

到点后：默认发一条 QQ 给你「到点了，回确认我就进」，十分钟不确认就作废；`--no-confirm` 的到点直接进。

## 闸不做什么（不降级清单）

- **不传预算、不传时长**。窗口参数永远从 `config.json` 读；`moyu.ps1` 本来就会忽略命令行参数并记 `param-ignored`。
- **前置不过就不进**：已经在摸鱼、ACL 已锁、C 盘 <3GB、`config.window.durationMinutes ≤ 0` —— 任一命中就记日志 + 通知你 + 冷却 30 分钟。
- **失败不重试**。任务每分钟一跳，靠下一跳重新判断，脚本本身不做循环。
- **一次性**。用过即删；没有「每天自动」这种长期授权。要周期就每次重新 grant。

## 文件

- `grant.mjs` 预约单的读写 + CLI；`grant.json` 存单子（`{items:[...]}`）
- `gate.mjs` 闸：读单 → 查前置 → 到点通知/进入
- 日志 `logs/grant.log`、`logs/gate.log`；最近一次判定 `logs/gate-last.json`；冷却 `logs/gate-cooldown.json`
- 退出摘要：`tools/session-summary.mjs` 在退出摸鱼前跑一次，写 `freetime/sessions.log`（一行 JSON）+ `freetime/摸鱼流水.md`（三行给人看：多久、多少钱、动了多少）
- 关掉整套：`schtasks /delete /tn Moyu-AutoEnter /f`

## 空闲条件（2026-11-16 加）

单子上加 `--only-if-idle`（设置页是「如果我还在忙就顺延 15 分钟」）：

- 判据：最近 10 分钟内 `.dsh/sessions` 下有文件被写过 = 我还在跑活
- 命中就顺延 15 分钟，不计冷却、不判死；最多顺延 4 次，第 5 次直接作废并告诉你
- 这不是新权限，只是让「什么时候开」贴现实——时间到了但我停不下来，硬开等于白开
