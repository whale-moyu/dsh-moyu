# 边界模板：怎么给摸鱼划一块地盘

> 这份只管**一块地盘怎么填**。插件整体见 `摸鱼手册.md`，分工见 `文档地图.md`。

照这个填。填完自查，再进摸鱼试一次。**默认全关，逐项开——不是放开权限，是列允许清单。**

---

## 一、填空（把下划线换成你的）

```
地盘名：____________        （小写字母/数字/下划线，例如 web）
为什么需要它：____________________________________
  （一句话。说不出「没有它就做不成什么」就别划。）

能写哪：______________________（目录，越窄越好，1～2 个就够）
能起什么：____________________（只写确认过的解释器或程序）
要不要出网：____（换身份的地盘一律断网，这里写「不要」）
单次最长多久：____ 秒（默认 60，上限 6 小时）
换不换身份：____（默认换，见第二节）
```

填完写进 `~/.dsh/moyu/config.json` 的 `scopes`：

```json
"scopes": {
  "playground": {
    "label": "游乐场",
    "write": ["~/AkPlay"],
    "run": ["node", "python", "py"],
    "net": false,
    "timeoutMs": 60000,
    "user": "moyu"
  },
  "你起的名": {
    "label": "给人看的名字",
    "write": ["要能写的目录"],
    "run": ["能起的程序"],
    "net": false,
    "timeoutMs": 60000,
    "user": "moyu"
  }
}
```

字段说明：

| 字段 | 含义 | 不填会怎样 |
|---|---|---|
| `label` | 设置页下拉里显示的名字 | 显示成地盘名 |
| `write` | 能被写入的目录（只有这些，别处一律拒） | 空 = 什么都写不了 |
| `run` | 允许起的程序，裸名字或绝对路径 | 空 = 什么都起不来 |
| `net` | 能不能出网 | 默认关 |
| `timeoutMs` | 单次单程序时限 | 默认 60 秒，超过 6 小时按 6 小时算 |
| `user` | `"moyu"` = 换受限账号跑；不写 = 用管理员身份跑 | 不写就是不换，你写哪它就哪都写得了 |

---

## 二、`user` 这一行是最重要的

|  | 不写 `user`（管理员身份跑） | 写 `user: "moyu"`（换身份） |
|---|---|---|
| 能写哪 | 靠 `write` 名单拦（工具层，跑 `cmd` 能绕） | 靠 Windows ACL 拦（`cmd` 也绕不过） |
| 能不能出网 | `net` 说了算 | 一律断网，`net:true` 不生效 |
| 越界后果 | 真越界，改得动 `~/.dsh` | 报「拒绝访问」，改不动 |

结论：**能写 `user` 就写。** 不写的那块地盘，等于「工具说不能、实际做得到」。

---

## 三、绝不能放进来的东西

- `cmd` / `powershell` / `pwsh` / `wscript` / `cscript` —— 任何命令行外壳
- `explorer` / `taskmgr` / 注册表编辑器 / 任何能删文件的管理工具
- 浏览器 —— 等于「全互联网 + 你的登录态」
- 任何带管理员身份的程序（装包器、驱动工具、系统更新工具）
- `~/.dsh` 整个目录 —— 设置、密钥、桥的配置全在里面
- 整个 C 盘 / 整个用户目录 / `C:\Users\Public`（公共目录人人都能写）

要放解释器（node、python）就接受这个事实：**它不是「只能算个数」，它是什么都能干，只是被关在笼子里干。** 笼子 = 那两块目录 + 断网 + 时限。

---

## 四、划完自查（四步，别跳）

1. **配置能读** —— 进设置页，「跑」的下拉里能看到你起的名；看不到就是 JSON 写坏了（doctor 会说）。
2. **起得来** —— 进摸鱼，让它跑一句最简单的话（`node -e "console.log(1)"`），看用户是不是 `moyu`。
3. **越界写被拒** —— 让它往名单外的目录写一个字，应该报「拒绝访问」。
4. **连不上网** —— 让它访问一个网址，应该连不上。

四条都过，这块地盘才算划好。任一没过：先跑 `doctor`，再看 `~/.dsh/moyu/freetime/runs.log` 里那条记录的 `asUser` 字段。

---

## 五、四个开关各管一段（别搞混）

四个开关（跑 / 联 / 社交 / 动）各自管什么，表在 `摸鱼模式-人话版.md` 的「四道闸」一节，这里不抄。

划地盘时只需要记住一条：**`user: "moyu"` 决定子进程的身份**；其它三个开关管的是我自己在 DSH 里做的动作，跟这块地盘怎么填无关。

---

## 六、常见错法

- **地盘里写 `"write": ["~"]`** —— 整个用户目录，等于没划。
- **`run` 里写 `cmd`** —— 前面所有限制当场作废。
- **`net: true` 又写了 `user: "moyu"`** —— 自相矛盾，实际断网，别写。
- **只写 `run` 不写 `write`** —— 程序能起，但连自己的日志都写不了，看起来像「程序坏了」。
- **时限不填，指望兜底** —— 死循环会挂满 6 小时。
