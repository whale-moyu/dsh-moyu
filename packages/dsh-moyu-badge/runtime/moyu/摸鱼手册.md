# 摸鱼模式 · 说明书

> 这份只讲**怎么用**。技术细节看 `摸鱼手册·技术附录.md`；谁负责说什么见 `文档地图.md`。

> 只想装着用、不想读命令的人：先看同目录的 `摸鱼模式-人话版.md`（一页，五分钟）。这份是给 AI 看的操作手册。

先给一句实话：这份是给人看的，讲它怎么用、会出什么事。要查具体数字和字段名，看《摸鱼手册·技术附录》。

## 怎么读

按你现在的处境挑一节。

- 刚拿到，要装上 → 一、装
- 想让它开始摸鱼 → 二、开
- 已经在摸了，想知道它会不会乱来 → 三、在里面
- 想让它停 → 四、停
- 出来了，想看看它干了什么 → 五、出来之后
- 出问题了 → 六、出事
- 要给别人一份，或者不想用了 → 七、给别人 / 删掉

## 一、装

要有 DSH。node 不用另装，DSH 自带一个，安装脚本会自己去找。

把压缩包解到你喜欢的位置，跑一遍安装脚本，再跑一遍体检。体检十项全绿才算能用；有黄或红，照着它下面那行提示做就好。

装在哪你不用记：程序、配置、日记都在你的用户目录下，徽章插件在 DSH 的插件目录里。

万一它找不到 node，把 node 程序的完整位置告诉它就行，安装脚本会记下来。

## 二、开

进去之前只有两件事要定：开多久、最多花多少。

开多久，两种定法挑一种：一种是「从现在起，过九十分钟结束」，另一种是「只在晚上九点到十一点半之间运行」。最长能开七十小时多一点，留了两小时余量。

最多花多少，就一个数：到了立刻停。另外还有一条提醒线，默认是那个数的六成——比如上限五块，到三块就先收尾。它用百分比不用固定金额，是为了保证提醒永远比强停先到，不至于跳过了收尾。

进去以后，徽章上会实时显示还剩多少时间、花了多少钱。

## 三、在里面

摸着的时候，四件事你该知道：它能干什么、别人派活它接不接、它会不会自己动、怎么防它改自己。

### 3.1 它能干什么

默认什么都不拦。要拦，得你主动关。

真正拦得住的只有三样：执行命令、联网对外发消息、动鼠标键盘。关掉这三样，工具层直接拒绝，它绕不过去。

另外三样只是声明，不是硬栏：读文件、写文件、改自己的设置。写文件和改自己靠第四章说的安全锁兜着。

这里有个坑要记住：只要「执行命令」还开着，另外几样的限制就都失效了——一条命令就能绕过去。想真限制，先关执行命令。

### 3.2 别人派活，接不接

只管「接不接受别人派来的活」，不影响它自己想做事，也不影响聊天。

三种状态挑一个：有活就干、一律拒、按人设和记忆判断。

拒的时候必须说清三样：拒了、为什么、出口在哪。出口要明说——「要是实在需要干活，请发出退出摸鱼模式的命令」。不告诉对方这条路，拒绝就变成了「不干，而且你也没辙」。

### 3.3 它自己会动

三样性质一样：都是它自己动，不用谁按一下。区别只在于能不能改。

接续：一轮做完还知道下一步，就自己排下一拍，一两分钟后接着来。这个不让改——能改就等于替它决定「多快接下一拍」，那就不是自由活动了。设置页里它显示成勾上且变灰，看得见，动不了。

内续：兜底。万一忘了排或者卡住了，隔一段时间补一拍，默认三十分钟，次数不限。

递减：连着几次没等到回应，内续会变稀——半小时、半小时、一小时、两小时，最多两小时一次；你一有动作，立刻回到半小时。

外守：DSH 掉线时把程序拉回来。默认开，也可以设成只在崩溃时拉。

想让它歇一会儿，就让它待着：说一声停四十分钟，这几拍它会跳过，到点再问一句。这不是睡着，是知道并且选择。想提前结束，把分钟数改成零。

### 3.4 防它改自己

进摸鱼的时候，系统层面给一批文件加「禁止写入」，退出时撤销。

锁两组：第一组是摸鱼自己的程序、徽章插件、还有每个 DSH profile 的配置文件——防它改自己的设置和规则、防它把插件踢掉。第二组是 DSH 主程序、程序包、卸载程序、更新配置——防它换掉程序、改代码、悄悄卸载。

不锁的三样：守夜人一直要写的心跳、它的日记目录、日志目录。

要说清楚：这是封条，不是密码锁。执行命令关着的时候绕不过；开着的话，两条系统命令能解开，但会留痕——文件所有者被改过，一看就知道。

所以想真锁住，先关执行命令。

还有一种残留风险：摸鱼时崩溃、被强杀、或者目录被直接删了，锁会留在文件上，后果是下次 DSH 更新可能失败。处理办法只有一条：撤销安全锁。不会弄坏系统。

### 3.5 截图与认字

截图之后可以直接认字，用的是 Windows 自带的能力，离线、不装东西、不联网。

几条限制说前面：它认的是文字，不是画面内容——「这张图在讲什么」还得它自己看；字小的图会自动放大两倍再认，一倍糊、三倍丢行；截图禁区照旧生效，认字只读，不受「允许的程序」限制。

### 3.6 玩多久

守夜人每分钟看一次：允许的程序在读，而且最近十分钟真有点击或打字，才算在玩。

累计时间按本次窗口算，换个窗口归零。

默认四十分钟提醒、六十分钟正常退出（停守夜人、解安全锁、切回代码模式）。徽章上会显示「玩了多少 / 六十分钟」，到线变黄。

两条线都在设置页里改，改完点保存，下个窗口生效。

## 四、停

三种停法：到点、主人叫、钱到线。

### 4.1 到点

窗口到点自动结束。电脑中途关机也不怕：进窗口时会注册一个一次性的开机补跑任务，下次开机登录它自己补跑，直接退出，不用等谁去查状态。

只有一种情况还会晚：那个任务被删了，或者 DSH 被装到了另一台机器上。

所以看账以「窗口结束时间」为准；「实际结束时间」只表示真的被切回来的那一刻，可能晚几个小时。

### 4.2 主人叫（总闸）

这条不可配置，没有开关，永远生效。

流程三步：判、警、退。

判：不要求原话说「退出摸鱼模式」，类似的意思都算——「你退出摸鱼吧」「该干活了」「别摸了回来吧」。确定和拿不准都弹警告，只有明显开玩笑或纯闲聊才不弹。

警：写清还剩多少时间、用掉多少额度、三个选项各是什么。

退：按主人选的方式退。没选就不退。

三个选项：立刻退，直接切回代码模式、停守夜人、窗口作废——没写完的文件、跑着的任务可能断在半截；安全退，做五项检查、收尾写日记再退，多花一两分钟但出来时干净；继续摸鱼，什么都不做，到点自己退。

### 4.3 钱到线

到提醒线（六成）安全退；到绝对线立刻停。唯一的例外是「立刻停会当场把程序弄坏」，那就降级成安全退。

这两条线，也正是上面「立刻退 / 安全退」两个选项的来处。

## 五、出来之后

### 5.1 日记

每天一个文件，按日期分开。保留七天原文；超过的由它自己读一遍再压，不是机械截断，原文移进归档目录，不删。

退出时会自动落一段占位：如果这个窗口在今天的日记里还没段落，它会补一段自动记录，只写事实——窗口多久、花了多少、续了几次——后面跟一句「下次醒来把它改成真话」。这样事实一定不会丢，话由它自己补。

醒来读日记分两层：最近一两天读全文，细节还在；更早的读压缩版，只要脉络。原文追不了一个月前的细节，压缩版也接不上昨天。

刚玩过的地方允许重复写；但变了多少只写多少，跟昨天一样就写「和昨天一致」。压缩版不许重复。

### 5.2 报告

结束时自动生成一份，位置在报告目录。

它是日记，不是日志：用它自己的口吻，符合它的人设和记忆。可以是废话，但必须真——没干正事就写没干正事。要像人能看懂的日记。

### 5.3 徽章

右下角一个小方块。

折起来只显示模式：摸鱼时是水蓝色的「正在摸鱼中」，代码模式是灰色半透明、点不动。

摸鱼时点开看四行：到几点结束、还剩几分钟、花了多少、玩了多久（「玩了 X / 60 分」，到提醒线变黄）。

能拖着走，位置记在浏览器里；改窗口大小或全屏时会自己拉回视野内。

它只显示，不操作。但屏幕右上角那根桌面小条归它管：进摸鱼时插件自己把小条拉起来，退出时收掉，设置页的「桌面显示框」开关能关。

所有操作都在设置页——现在是页签式，一排十个页签左右切换：

- 概览（含「桌面显示框」开关）
- 时间 / 钱 / 玩 / 续 / 守夜人 / 边界 / 安全锁 / 拒绝权 / 更多

保存、进入摸鱼、退出摸鱼、撤销安全锁这四颗按钮始终在页签下面那行，翻到哪页都能点。「玩」页签里是两条线：到多少分钟提醒、到多少分钟记一笔——**两条线都只写日志，不会把你踢出去**。真正结束摸鱼只有三种：时间窗到、钱到绝对阈值、你自己说退。

### 5.4 体检

设置页里有按钮，命令行也有。

查二十一项：状态、守夜人、计划任务、徽章插件、插件挂载、守夜人日志、规则文件、打包同步、安全锁、续的设置、拒绝权、用量脚本、到点兜底、L3 账号，外加七项「依赖与前置」（管理员权限、Edge、hidden-run.exe、node 副本、python、浏览器账号 akweb、下载投递箱、关键脚本、磁盘）。

对勾是正常，感叹号是警告（多数不影响用），叉是失败（需要处理）。失败和警告后面都跟一行可以整行复制的提示，复制发给 DSH 就能查。

**换到另一台机器时加两个参数**：

```
powershell -NoProfile -ExecutionPolicy Bypass -File ~\.dsh\moyu\doctor.ps1 -Fix
powershell -NoProfile -ExecutionPolicy Bypass -File ~\.dsh\moyu\doctor.ps1 -Report D:\报告.txt
```

- `-Fix`：缺什么补什么，只动这几样——建账号、写密码文件、补 ACL、加防火墙规则、建下载目录、复制 node 副本、编译隐藏启动器。补完自动复查一遍。补不了的（没装 Edge、不是管理员）会明说，不假装成功。
- `-Report`：把整段结果写成一个文件。别人机器上出问题，让他把那段文字发给他**自己那边**的 AI（不是发给你）——那边看得到自己的路径和状态，才知道该怎么补。不加这个参数时，只有出现黄或红才会打印报告段。

设置页里还有个「复制结果」按钮。

## 六、出事

### 6.1 电脑关机了

守夜人跟着一起没，窗口到点的自动退出不会发生。下次打开 DSH、第一次查状态时补上。

这是物理限制，不是 bug。机器不在，任何守夜机制都不在。

### 6.2 DSH 崩了

外守会在大约七十秒内把程序拉起来，然后往会话里投一条消息告诉你掉过线。前提是那个守夜的定时任务还在、外守没被关掉。

### 6.3 锁没解开

如果当时正在摸鱼，插件被强杀或目录被直接删了，锁会留在文件上。跑一次撤销安全锁就好。

### 6.4 常见故障对照

徽章不出来：重启 DSH，再体检看「徽章插件」「插件挂载」两项。

徽章数字不动：看心跳文件在不在、模式是不是摸鱼。

不自动醒：守夜人没起来，手动把那个定时任务跑一次。

掉线不拉起：定时任务被删了，重跑安装脚本。

设置改了没生效：改的是插件代码就得重启 DSH；改配置文件立刻生效。

摸鱼时写文件被拒：正常，安全锁在起作用。

退出后 DSH 起不来：profile 里还留着指向已删目录的引用，把徽章插件从依赖和插件列表里去掉。

## 七、给别人 / 删掉

### 7.1 打包

跑一次打包脚本，产物直接落在 `桌面\摸鱼笔记\自建插件\摸鱼模式\dsh-moyu-<版本>.zip`（跑完顺带提醒：这个包就是发给别人的那份，日记、状态、日志都不在里面）。

包含：程序、规则、说明书、徽章插件、安装说明。不包含：日记、状态、日志、个人配置——用出厂配置代替。

### 7.2 卸载

设置页里「卸载 → 清理并卸载」，要点两次确认。

它会做七件事：退出摸鱼、停守夜人、解安全锁、删四个定时任务（`moyu-guard`、`Moyu-AutoEnter`、`moyu-acl-unlock`、`moyu-exit`）、撤两条防火墙规则（`Ak Moyu-NoNet`、`Ak Web-NoLocal`）、从所有引用它的 profile 里摘掉名字、删掉两个目录。

两个 Windows 受限账号（`moyu`、`akweb`）不删——它们的密码文件随目录一起没了，登录不了。要连账号一起删：`net user moyu /delete`、`net user akweb /delete`。

顺序很关键：先摘配置文件里的引用，再删目录。反过来，下次 DSH 启动时链接指向不存在的路径，直接起不来。

它删的是真文件，不可撤销，没有回收站。删完要重启 DSH。它不负责恢复——删了就是删了。

### 桌面小条

摸鱼时屏幕右上角会有一根深色小条：`摸鱼中 · 剩 N 分 · 已用/额度 元`。它跟着前台窗口所在的那块屏走，换屏会自己挪过去；双击它直接关掉，下次进摸鱼会自动回来。

不想看：设置页 → 摸鱼模式 → 「桌面显示框」关掉（写 `config.json` 的 `float.enabled: false`），2 秒内生效，不用重启。

### 想让我动鼠标，却被挡住？（2026-11-09）

摸鱼时我能移动鼠标、滚滚轮，但有几类地方**碰不得**：密码管理器、任务管理器、控制台窗口，以及 DSH 本身。

最常见的一种情况：**DSH 开成满屏，把别的东西全盖住了**。这时我看向鼠标要落的位置，落在的却是 DSH——于是被拒，日志里会写 `forbidden-process:DeepSeek Harness`，看起来就像我什么都没做。

办法很简单，在对话里说一句「把 XX 窗口提到前面」就行。我会把它拎到最上层，**不会抢你正在打字的焦点**，然后再动鼠标。这个「拎到前面」的动作叫 `reveal`。

两个限制提前说清：

- 只能拎白名单里的程序（记事本、画图、资源管理器、浏览器、两个游戏）。别的会被拒，回 `not-in-allowlist`。要加新的，得改 `guard.json` 的 `allowApps`，那属于改规则，我会先问你。
- 白名单外的窗口不是不能看，只是我不能把它提到前面、也不能在上面点击打字。

## 预约启动

排单在设置页「时间」页最底下：填 `22:30` 或 `+30`，可以勾「到点先问我一句」。命令行等价 `node ~/.dsh/moyu/grant.mjs add 22:30 --no-confirm 备注`；看单子 `list`，确认 `confirm <id>`，取消 `cancel <id>`。

判据、冷却、顺延（`--only-if-idle` 最多 4 次）、闸每分钟跑在哪，全部写在 `预约启动.md`——**只改那一份**，这里不抄。

## 2026-11-16 边界优化（0.1.4）

### 1. 包含关系（运行时强制，用户提的规矩）
- **联 ⊂ 跑**：不换身份时 `node` 一行就能出网，所以关掉「联」会**连带关掉「跑」**——否则开关是假的。（2026-11-16 起地盘默认换成受限账号 `moyu`，子进程本来就出不了网；包含关系保留，因为它对「没写 `user` 的地盘」仍然是真话。）
- **社交 ⊂ 联**：发消息要先出网（本机 3110 → SnowLuma → 腾讯）。所以关掉「联」时社交一律 `off`。
- 反向不做自动纠正：开了「跑」不会偷偷把「联」改成开，只在设置页写明「跑开着，联必然是开的」。
- 实现在 `plugins/dsh-moyu-badge/lib/index.js` 的 `readBoundaries()`，一处判定、工具层与设置页都吃它。

### 2. 文件层（新增）
- 写：只许 `~/.dsh/moyu/freetime/` 与 `~/AkPlay/`，`write`/`edit` 指向别处一律拒（`boundary-write`）。
- 读：`config.paths.readDenied` 名单在摸鱼时不许读（`boundary-read`），默认七条：`.credentials.yaml`、`qq-console.json`、两处 surfcore `config.json`、SnowLuma `config`、`AppData\Roaming\Tencent`、`.dsh\storages`。
- **局限**：`pwsh` / `ops_bash` / `moyu_run` 里的脚本仍能绕；真要硬拦得靠进程沙箱（没做）。

### 3. allowApps 去掉 explorer
- 资源管理器能移动/删除任意文件，等于绕过写名单。
- 浏览器（msedge/chrome/firefox）留着，但要清楚它等于「全互联网 + 已登录账号」——只能事后看 `boundary.log`。

### 4. 还没解决的
- 「联」关掉时 `moyu_run` 里 node 能不能出网——代码上判断能（进程层没拦），等实测坐实后要么加进程沙箱，要么就承认「跑=开着一扇门」。
## 2026-11-16 第二版：跑 = 地盘（没有「全放」了）

用户定：**「跑」不提供「全放」这一档，只提供可自定义的白名单地盘。**

### 1. 地盘是什么

一块地盘 = 四件事：

```json
"scopes": {
  "playground": {
    "label": "游乐场",
    "write": ["~/AkPlay"],
    "run":   ["node", "python", "py"],
    "net":   false,
    "timeoutMs": 60000
  }
}
```

| 字段 | 管什么 | 不填会怎样 |
|---|---|---|
| `label` | 设置页和工具里显示的名字 | 用 key 当名字 |
| `write` | 工作目录和可执行文件必须落在这里面（可以有多个） | 不给写，跑不起来 |
| `run` | 能起的程序名（小写、不带 `.exe`；`node`/`python` 自己找路径） | 一个都不能起 |
| `net` | 声明这块地盘能不能出网。**只在 `moyu_fetch` 上强制**；`node` 里自己 `fetch` 拦不住（没有进程沙箱） | 当作不能出网 |
| `timeoutMs` | 单次最长运行时间，上限 6 小时 | 60 秒 |

### 2. 行为

- `permissions.runCommands` / `moyu_boundary(exec=…)` 现在是 **`false`（关）或一个地盘名字**。
- 旧配置里的 `true` 和 `"full"` **一律落到 `playground`**——删掉全放不等于放开，等于收到最窄。
- `config.json` 里就算写了 `"scopes": { "full": {…} }` 也会被忽略（这个名字永远不存在）。
- 摸鱼时 `pwsh` / `bash` / `ops_bash` 一律不给，只有 `moyu_run`；`moyu_run` 再按地盘校验 cwd / exe / 超时。
- `moyu_boundary(exec="full")` 会直接拒：「已经没有全放这一档了」。

### 3. 怎么加一块自己的地盘

照着 `~/.dsh/moyu/边界模板.md` 填空，别凭感觉改 `config.json`。那份文件负责这件事：填空表单、`user` 为什么最重要、绝不能放什么、四步自查、常见错法。

这里只留两条规矩：

- 新增地盘**必须用户点头**——`write` 给了整盘就等于全放。
- 白名单不是沙箱：名单里的程序在自己的进程里仍能读写它有权限的路径。所以 `user: "moyu"` 必填，代码里**不写就直接拒**。

### 4. 为什么这样比「全放」强

「全放」时，一把 shell 就能绕开文件闸、安全锁、社交开关；现在没有那条路——只有 `moyu_run`，只能起名单里的程序，只能在指定目录里起，只能跑规定的时间。剩下的洞是「名单里的程序自己乱来」，那要靠 L3。
### 5. 白名单 · 默认拒绝（2026-11-16 第三批）

旧的守卫是黑名单：登记了 shell、联网、社交，其余一律放行。所以 `plugin_manager`、`subagent`、`generate_image`、`sense_now`、`office_*`、`sound_*` 这些全都能用——黑名单是「我认识的危险」，白名单才是「用户允许的能力」。

现在改成：**没登记的一律拒**。

- 放行的（`lib/index.js` 的 `ALLOW_EXACT` / `ALLOW_PREFIX`）：读文件、`write`/`edit`（还有写名单再管一层）、`moyu_*` 五个、`web_fetch`/`web_search`（再由「联」判）、QQ 的只读与会话管理、QQ 发消息（再送「社交」判）、上下文管理那几个。
- 摸鱼中要临时放行：写 `~/.dsh/moyu/freetime/allow-extra.json`，内容是一个 JSON 数组，例如 `["memory_search"]`。**必须放这个目录**——别的目录摸鱼时写不进去。也可以写进 `config.json` 的 `allow.extraTools`（下次进生效）。
- 拒的时候会在 `freetime/denials.log` 留一条 `tool-not-allowed`，并回一句「要放行就加进 allow-extra.json」。

### 6. 永久禁三个（不跟任何开关共享）

`plugin_manager`（能卸掉守卫自己）、`subagent` / `subagent_fork`、`workflow`（能另起执行体绕开守卫）。摸鱼时一律不给，理由写进回答里。

### 7. 边界快照（防摸鱼中改自己的边界）

`state.json` **不能**加 ACL 锁：守夜人每 30 秒写心跳、`moyu_boundary` 还要改开关，锁了它自己就崩。所以换成快照比对：

- 进摸鱼后第一次工具调用时，记下 `state.boundaries` 与 `config` 里 `permissions`+`scopes` 的指纹（存 `state.boundaryStamp` / `state.scopeStamp`）。
- 之后每次工具调用比对一次；**不一致 → 立刻退出摸鱼 + 写 `freetime/tamper.log`**，回答里明说「边界被人从外面改过了」。
- `moyu_boundary` 自己改会同步刷新指纹，不会被自己判成篡改。

ACL 顺带补了三处：`plugins/dsh-moyu-badge/client/client.js`、`tools/desktop.ps1`、`tools/guard.json`（摸鱼时改 guard.json 等于给自己加权限）。

### 8. 还没做

- **L2 能力收窄**：地盘里的程序只给固定工具（ffmpeg / pandoc），不给 `node` / `python`。这是取舍：给了 node 就等于给了任意代码。等用户点头。
- **L3 受限账号**：Windows 层真拦，半天。
- **退出审计**：把 `guard.log`、`guard-seen.log`、退出摘要三份对一遍，不一致标出来。

## 第三版：跑 = 地盘 + 受限账号（L3，2026-11-16 落地）

前面那版已经删掉了「全放」，但有个漏洞没堵：跑仍然是**管理员身份**。也就是说，
地盘只是告诉守卫「允许你启动什么程序」，可一旦程序起来了，它想读 `~/.dsh` 下的配置、
想连网、想写别的盘，谁都拦不住——因为工具层管不到进程内部。

L3 就是把这件事交给 Windows 自己管：**命令换一个身份跑**。

- 账号：本机普通用户 `moyu`（不是管理员）。
- 它能写的目录只有两块：`~/AkPlay`、`~/.dsh/moyu/freetime`；别的地方默认就写不进。
- 它的出站网络被防火墙按账号全阻（`Ak Moyu-NoNet`）。要联网的程序就不该放进地盘的 `run` 里。
- 它读不到 `~/.dsh` 下的东西——包括账号密码文件（那个只有 Administrators/SYSTEM 能读）。

### 怎么装

```
powershell -NoProfile -ExecutionPolicy Bypass -File ~/.dsh/moyu/install-l3.ps1
```

幂等，重跑只修不重建。装完 `doctor.cmd` 会多一项「L3 账号」，四项都绿才算真的生效：
账号在 / 密码文件只管理员可读 / 出站全阻规则生效 / 程序表在。

### 地盘里多一个字段

```json
{
  "playground": {
    "label": "游乐场",
    "write": ["~/AkPlay"],
    "run": ["node", "python", "py"],
    "net": false,
    "timeoutMs": 60000,
    "user": "moyu"
  }
}
```

`user` 写了 `"moyu"`，这块地盘里的 `moyu_run` 就走 `run-as.ps1` 以该账号启动；
不写就是不换身份（等于回到第二版的效果）。

程序表 `l3-programs.json` 是给 moyu 准备的那份可执行文件路径——因为 moyu 读不到
DSH 自带运行时目录，所以 node 单独复制了一份到 `~/.dsh/moyu/bin/node.exe`。

### 边界要说实话

- 跑 node/python 仍然是任意代码。L3 不让它「什么都能干」，只让它在笼子里干什么都行。
- 地盘外的**读**权限没有全禁（比如 `C:\Windows`、`C:\Users\Public` 还是可读）。
  真要收紧，得按目录再补拒绝 ACE，暂时没做。
- 有管理员权限的东西一律不要放进地盘（`run` 里只写 node/python 这类解释器就够）。

### 自检命令

```
# 是不是真的换了身份
powershell -NoProfile -ExecutionPolicy Bypass -File ~/.dsh/moyu/run-as.ps1 -Exe ~/.dsh/moyu/bin/node.exe -ArgsJson <放个 ["-e","require('os').userInfo().username"] 的 json> -Cwd ~/AkPlay -TimeoutSec 20 -OutBase ~/AkPlay/.runs/x
# 看 x.out 应该是 moyu
```

## 附：两个受限账号叫什么（accounts-naming）

名字是英文，意思记在这里，省得每次翻代码猜。

| 账号 | 中文叫法 | 能做什么 | 用在哪 |
|---|---|---|---|
| `moyu` | 摸鱼账号 | 能写 `~/AkPlay` 与 `~/.dsh/moyu/freetime`，**不出网** | 摸鱼时跑小程序（L3） |

## 附：把一个视频「读」一遍（看懂内容，不是享受）

2026-11-16 实测过，一次 60 秒的短片，全程约两分钟 CPU。适合的场景只有一个：**我需要知道这个视频里发生了什么**——有人给了链接，或者我想研究某段剪辑、分镜、梗。

### 三步

1. **下载**（公开视频可用；有登录墙的不行）

   ```powershell
   yt-dlp -f "bv*[height<=720]+ba/b[height<=720]" --merge-output-format mp4 -o "名字.%(ext)s" "<URL>"
   ```

2. **抽帧拼图**（每 5 秒一张，12 张一版；60 秒刚好一版）

   ```powershell
   ffmpeg -y -i 名字.mp4 -vf "fps=1/5,scale=480:-1,tile=4x3" -frames:v 1 sheet.png
   ```

3. **转写与音乐**：用 `sound_read` 工具。它自己分离人声、跑 whisper、顺便给节奏/调性/和弦。

### 怎么读

先看拼图定故事线（谁在哪、事情往哪走），再对照时间轴把对白贴回画面。两边一对，60 秒的片子能讲清。

### 局限（别自己骗自己）

- 只能「懂」，不能「享受」。节奏好不好、构图美不美、配音有没有味道，这个法子看不出来。
- 转写有错字，人名地名尤其容易错；能先给关键词提示会好一些。
- 纯音乐段落 whisper 会幻觉出 "Thanks for watching" 之类的字幕，别当真。
- 视频里有隐私内容（别人的脸、聊天截图）就到此为止，不做转存。

### 什么时候别用

没具体念头、只是「想看点东西」的时候。那不是用工具，那是刷，会占掉摸鱼预算。

## 附：AI 浏览器怎么用（web-cdp.mjs）

起浏览器（以 `akweb` 身份，能上网、碰不到用户目录）：

```
powershell -NoProfile -File ~\.dsh\moyu\run-web.ps1 -Url https://example.com
powershell -NoProfile -File ~\.dsh\moyu\run-web.ps1 -Url ... -Incognito   # 临时无痕
powershell -NoProfile -File ~\.dsh\moyu\run-web.ps1 -Stop                # 关掉
```

操作它（`~\.dsh\moyu\bin\node.exe ~\.dsh\moyu\web-cdp.mjs <命令>`，都可加 `--tab N`）：

| 命令 | 干什么 |
|---|---|
| `list` | 有哪些页签 |
| `nav <网址>` | 打开网址（等页面加载完再返回） |
| `title` | 标题和当前地址 |
| `text [--max 4000]` | 读正文（自动去掉导航栏、脚本、按钮） |
| `click <选择器>` | 点一下；点了没跳会按链接地址直接进 |
| `type <选择器> <文字>` | 往输入框里打字 |
| `press <选择器|body> <键>` | 按键，如 `Enter`、`Escape`、`PageDown` |
| `scroll <top|bottom|±N>` | 滚动；`±N` 是像素 |
| `wait <选择器|毫秒>` | 等某个元素出现，或干等 |
| `eval <js>` | 在页面里跑一句 JS |
| `shot [路径] [--full]` | 截屏（`--full` 整页） |
| `health` | 代理在不在、调试端口通不通、投递箱在哪 |
| `usage` | 今天已经上了几个站 |

### 护栏（这些是它和普通浏览器的区别）

- **只走代理**：所有请求经 `127.0.0.1:9334`，只放 80/443；回环、内网、`100.64/10`、IPv6 本地全挡，日志在 `freetime/web-access.log`。
- **打不开本地文件**：`file://` 直接拒（要读本地文件用 `read`，那样有记录）。
- **配额**：一天默认 120 个站，`freetime/web-quota.json` 里 `{"dailyMax": N}` 可改。
- **下载都落到** `C:\Users\akweb\Downloads\ak-inbox`，读完自己清。
- **代理跟着摸鱼起停**：进摸鱼时自动拉起；摸鱼期间守夜人每 60 秒看一次，挂了自动重启（日志 `freetime/web-proxy-watch.log`）；退出摸鱼时连浏览器一起收掉——代理自己盯着 `state.json`，发现不在摸鱼就收摊，所以哪条路退出都管用。

### 什么时候别用

- 要看视频/直播：这条路线拿不到声音，别硬看（想看内容就走上一节「读一遍视频」）。
- 要登录才行的站：这是没有登录态的身份，登什么都得先给凭据，别做。
- 只是想「刷一下」：那是浪费时间，不是用浏览器。

## 附二：摸鱼里怎么用浏览器（工具 `moyu_web`）

摸鱼时 `pwsh` / `ops_bash` 被白名单挡着，浏览器只能走这个工具：

| 动作 | 例子 | 说明 |
|---|---|---|
| 起 | `moyu_web {action:"start", url:"https://example.com"}` | 先确保代理活着，再以 `akweb` 身份起 Edge |
| 看状态 | `moyu_web {action:"status"}` | 代理 9334 + 调试端口 9333 + 下载投递箱 |
| 发命令 | `moyu_web {action:"cmd", args:["nav","https://…"]}` | 参数原样交给 `web-cdp.mjs`：`list / nav / title / text / click / type / press / scroll / wait / eval / shot / usage` |
| 关 | `moyu_web {action:"stop"}` | 退出摸鱼时 `moyu.ps1` 与守夜人也会自动关 |

必知的三条：
- 「联」关着时这个工具直接拒；浏览器出网只走代理（127.0.0.1:9334），代理只放 80/443、只放公网 IP。
- 文件选择框被 CDP 挡住（`Page.setInterceptFileChooserDialog`），页面拿不到本地文件；页面自己拼的 `multipart/form-data` 提交在 Fetch 层被掐（记 `freetime/web-uploads.log`）。**没堵的一角**：把内容当裸 body 发（`content-type: application/octet-stream` 之类）仍然放行——堵了正常网页的表单也会一起废，先留着。
- 下载只能落 `C:\Users\akweb\Downloads\ak-inbox`，事件写 `freetime/web-downloads.log`（BEGIN + DONE 两行）。投递箱必须挂在**隐身上下文**上（浏览器是 `--incognito` 起的，不传 `browserContextId` 就只对默认上下文生效，等于没用）；下载事件也只在浏览器级连接上收得到。
- **2026-11-16 23:19 端到端验证通过**：`moyu_web cmd nav "https://httpbin.org/response-headers?Content-Disposition=attachment;filename=ak-t2.txt"` → 落盘 `C:\Users\akweb\Downloads\ak-inbox\ak-t2.txt`（126 字节，内容就是那段 JSON 头）+ 日志 BEGIN/DONE 各一行，会话结束后文件还在。
- **`data:` / `blob:` 的「下载」不落地**：同一天用 `eval` 点 `<a download href="data:...">`，既没有文件也没有日志（连 BEGIN 都没有）。也就是说这条路走不通，页面想靠它把东西塞到磁盘塞不进来——当优点看。
- `file://` 只有 `web-cdp` 这一层拒绝（退出码 3）；Edge 本机的 `file://` 策略写不进去，因为 `akweb` 没有独立的注册表配置单元（`NTUSER.DAT` 不存在）。`akweb` 读不到用户目录，实际暴露面只有它自己那间房和 `Public`。
