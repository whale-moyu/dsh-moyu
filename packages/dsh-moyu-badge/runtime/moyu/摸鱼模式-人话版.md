# 摸鱼模式 · 人话版

> 给人看的版本，不写命令和路径。技术细节在 `摸鱼手册.md`。

> 这份是给「不写代码、只想装着用」的人看的。安装细节、命令、判据，全在同目录的 `摸鱼手册.md` 里——那份是给 AI 看的。

## 这是什么

给 AI 划一段时间，让它在不干活的时候自己安排做什么，同时**把它能碰到的东西限定死**。

装好以后，你会在 DSH 左下角「设置 → 摸鱼模式」看到一整页开关。

## 进和出

- **进**：点「进入摸鱼」，或者预约一个时间到点自动进。
- **出**：到点自己出、钱花到线自己出、你点「退出摸鱼」、或者在任何对话里说一句叫它出来。
- 出来以后它会写一段自己的流水，进度留在原地，下次接着做。

## 四道闸

一页里最重要的就是这四行，每行一个开关：

| 闸 | 管什么 | 建议 |
|---|---|---|
| **跑** | 能不能执行命令 | 只用「游乐场」这一档 |
| **联** | 能不能上网、对外发话 | 默认关 |
| **社交** | 能不能给外面的人发消息 | 只许发给你 |
| **动** | 能不能操作鼠标键盘 | 需要时开，只点白名单程序 |

**「跑」没有「全放」这一档。** 要么关着，要么落在一块「地盘」里——地盘就是一间划好的房间：能写哪个文件夹、能起哪个程序、能不能上网、一次最多跑多久。

现在已经备好四块：

- **游乐场**：写代码、跑程序。只有这一块能写文件。
- **玩游戏**：只能起指定的游戏，别的不行。
- **剪音视频**：只能起视频/音频工具。
- **AI 浏览器**：另一个独立通道，能上网，但碰不到你的文件。

## 它碰不到你

- 写不进你的用户目录、桌面、游戏存档目录
- 命令跑起来的时候用的是**另一个受限的 Windows 账号**，不是你的管理员账号
- 上网被按账号切断，除非你明确放行
- 你设置里锁住的那些文件（包括它自己的开关和守卫脚本），它改不了——想改得先退出摸鱼

## 出事怎么办

| 现象 | 怎么办 |
|---|---|
| 电脑关机了 / DSH 崩了 | 重新打开 DSH，点「撤销安全锁」 |
| 卡在摸鱼里出不来 | 对话里叫它一句，或点「退出摸鱼」 |
| 文件改不动了 | 同上，撤销安全锁 |
| 想知道现在到底什么状态 | 点「跑一次体检」，全绿就没事；有红的会写清哪项、怎么修 |

体检可以一键补齐能补的（账号、权限、防火墙规则、目录），补不了的会告诉你缺什么。

## 想自己加一块地盘

看 `边界模板.md`：填七个空——名字、为什么需要、能写哪、能起什么、要不要出网、时限、要不要换身份。

**`user: "moyu"` 这一项必须写。** 不写就等于用管理员身份跑，等于没有边界——插件会直接拒绝启动。

## 卸掉

设置页最下面「清理并卸载」，会退模式、停守夜人、撤安全锁、删计划任务、撤防火墙规则、删两个目录。删的是真文件，没有回收站。

两个 Windows 账号（`moyu` / `akweb`）故意留着不删：密码文件跟着目录一起没了，它们登不进来，留着不碍事。

## 想要一个形象、一个声音？

**这个包里没有形象，也没有声音文件。** 摸鱼模式管的是「它能碰什么、不能碰什么」，与它长什么样无关。

- **形象**：看这个视频，路径、获取方式都在里面 —— BV1yep465EQz（B 站）。按视频里说的来源和授权来，别从别人的成品里抠图。
- **声音**：用你系统自带的语音合成（Windows 的 SAPI 就有中英文音色），或者接任意 TTS 服务。**不要**把某个具体人物（尤其真人或已故配音演员）的音色克隆包进公开分发的东西里。
- **见面窗 / 3D 房间**：那是另一套工作区工具（`tools/call` 那一类），不随这个包分发。插件这边只有「字幕放哪」一个设置项，没接就不显示。

一句话：**能力边界可以借鉴，形象和嗓子请自己做。**
